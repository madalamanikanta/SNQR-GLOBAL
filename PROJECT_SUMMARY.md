## 🔧 How to Use

### Start Development
```bash
pnpm dev
```
Opens [http://localhost:3000](http://localhost:3000) with hot reload.

### Customize
1. **Colors** - Edit `/app/globals.css` theme variables
2. **Content** - Replace mock data in components
3. **Pages** - Add new routes in `/app`
4. **Components** - Create new components in `/components`

### Deploy
```bash
vercel deploy --prod
```
